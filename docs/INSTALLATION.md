# Installation

1. Install a compatible LSPosed/Xposed framework.
2. Install `Deekseep.apk` from the current GitHub release.
3. Enable Deekseep and scope it only to `com.deepseek.chat`.
4. Force-stop and reopen DeepSeek.

DeepSeek 2.3.4 is recommended. Versions 2.2.0 and 2.3.0 are retained for
compatibility, with possible feature limitations. Versions 2.3.1 through 2.3.3
are not supported.

Back up important conversations before enabling experimental functions. If the
host becomes unstable, disable the affected function or the module and restart
DeepSeek.
