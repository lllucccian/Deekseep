# 背景空间视差（实验分支）

> 分支：`experiment/spatial-depth-3d`。空间场景使用同一个虚拟相机状态驱动所有平面，
> 不给单个气泡增加独立滤波或摇摆。

## 光学模型与层级

姿态角使用半球相机的横向投影比例：

`opticalUnit = sin(relativeAngle) / sin(5°)`

它不是弹簧动画。传感器产生的新姿态在下一次屏幕刷新直接显示，并根据相邻的绝对姿态
只预测传感器年龄加显示扫描所需的 `8～24ms`；预测不会累计，因此不会产生陀螺仪漂移。
与 `tan()` 不同，手机经过侧立姿态时不会出现无穷大或突然换边。当前
“稍强（1.25×）”在相对倾斜 `5°` 时对应：

- 后景补全底图：`5dp`。
- 抠出的人物/主体中景：同方向 `1.5dp`。
- DeepSeek 文字、聊天框和输入控件：反方向 `0.65dp`。
- 最上层玻璃：`0dp`，保持屏幕表面稳定。

默认方向按真机预览校准：手机向左时后景向左；手机向面部方向前倾时后景向上，
前景 UI 反向轻移，露出原本被遮挡的后景。“反转动效方向”只改统一方向系数。

## 抠图与补洞

原始导入图始终保留，不会被覆盖。首次开启空间动效时，后台线程在 DeepSeek 私有目录生成
两张派生缓存：

1. 使用边缘连通背景检测得到带羽化透明边的主体中景。
2. 只用轮廓外的已知背景像素建立二维低频颜色场，并填入主体原来占据的区域，得到完整后景。

中景移动后露出的是补全后的背景，不是透明洞。当前线稿/渐变类背景不需要体积很大的通用
语义分割库；掩码结果异常（主体小于 2% 或大于 92%）时会拒绝分层并安全退回原图。
缓存键包含原图路径、大小、修改时间和算法版本，换图后不会误用旧结果。

## 接入与生命周期

- 壁纸和中景复用同一套显示方式、全屏/半屏范围、横纵取景、连续缩放、焦点与旋转参数；
  空间模式不再硬编码 `crop`，也不额外放大图片。聊天外观页保存后会立即重建空间图层。
- 取景矩阵只相对手机当前可见窗口计算；为位移预留的超大防露边画布只提供外围 bleed，
  不参与 crop/fit/stretch 的比例或焦点计算，因此扩大画布不会吞掉横纵取景和缩放。
- “外沿颜色无限延伸”是空间子页中的独立开关。开启时用 CLAMP 沿用原图最外圈颜色铺满
  整个扩展画布；关闭时严格沿用聊天外观里的截断、镜像或边缘延展选择。
- 宿主 `AndroidComposeView` 只在场景绑定时定位一次，逐帧只写三个平面的
  `translationX/Y`，不遍历 View 树，不创建 Bitmap/Drawable，不拦截触摸。
- 旧的陀螺仪累计和摇晃弹簧在空间模式下停止。传感器偏移直接跟手；侧栏与设置页的确定性
  基础位移单独复用普通壁纸原有的延迟跟随/路由缓出，再在唯一写入点与传感器偏移相加。
- `TYPE_GAME_ROTATION_VECTOR` 优先，回退 `TYPE_ROTATION_VECTOR`，绝不积分原始陀螺仪。
- 首帧为零点；用 `referenceᵀ × current` 计算局部姿态，并处理四个屏幕方向，因此手机
  初始拿歪也不会把前后倾斜串成左右移动。
- 传感器使用 `SENSOR_DELAY_FASTEST`；回调只更新目标、速度和时间戳，
  `Choreographer` 每帧最多分发一次。
- 连续稳定 `650ms` 后，仅在 `0.05°` 的传感器零误差窗口内缓慢修正参考姿态。
- `onResume` 注册，`onPause`/不可见时注销；Activity 销毁时移除回调和弱引用。
- 减少动态、省电模式或无传感器时关闭动态位移，保留静态分层和防露边。

## 参数位置

- 半球投影基准、旋转矩阵、零点校准：`SpatialMotionController.java`。
- `5 : 1.5 : -0.65 : 0` 的距离比例、背景缩放和画布余量：`ChatAppearance.java` 的
  `SPATIAL_BACKGROUND_*`、`SPATIAL_MIDGROUND_TO_BACKGROUND_RATIO`、
  `SPATIAL_FOREGROUND_TO_BACKGROUND_RATIO`、`SPATIAL_BACKGROUND_SCALE`。
- 抠图、补洞和派生缓存：`SpatialLayerCache.java` 与 `ImageCutoutUi.detectBackgroundMask()`。
- 彩蛋页只保留“空间动效”入口按钮；总开关、强度、外沿延伸、减少动态、自动校准、方向和
  手动校准全部位于 `SpatialMotionUi.java` 的专属子页。
